Composio integration — what was actually demonstrated

  • Transport: Composio Connect MCP endpoint (https://connect.composio.dev/mcp, consumer API key). The Composio SDK was not demonstrated: the key supplied was a consumer MCP key and the SDK returned 401.
  • Tools executed through COMPOSIO_MULTI_EXECUTE_TOOL: TINYFISH_SEARCH_WEB and TINYFISH_FETCH_URLS; discovery via COMPOSIO_SEARCH_TOOLS. Each response was checked for instant_charge == 0 and the run aborts on any charge.
  • Not demonstrated: Composio toolkit schemas/auth for the 100 apps were not inspected, so no integration claim is made from a toolkit name. The Neo4j catalog inspection is prepared (separate surfaces) but not part of these figures.

Design decisions that matter

  • Frozen prompt/schema/baseline never modified; corrections go to new versioned runs.
  • Evidence reduction exists only because of Groq’s 8k tokens/min cap; it measurably changed an answer (Finding 1), so it is versioned and shown.
  • Single-writer lock, atomic read-only checkpoints, hash-chained request log, circuit breaker, per-bucket quota with rolling token window.

4 · Verification

Extraction and verification by the same model family are not independent. Structural validation, JSON validity, lexical quote matching and model agreement are not accuracy measurements.

Five-app correction: preserved original vs corrected (Groq)

Evidence validation — what is checked

  • Rejected as evidence: placeholder quotes (“unknown”), ellipsis-stitched quotes, quotes not contiguous in the cited page, URLs not in the retrieved ledger, quotes outside the evidence the model was shown (possible recall from memory).
  • A failed quote check means the evidence does not support the claim as submitted — not that the claim is false.
  • A generic explanation of MCP is not evidence that a given app has an MCP server (see GitHub).

Earlier verifier (baseline Pass 2, Groq) — historical, known weaknesses

Human evaluation

  • 0 labels exist. Blind sheets (84 claims per frame, three frames + calibration) are prepared, sealed and empty.
  • Protocol: two independent labelers, one adjudicator, truth frozen by hash before any model output is unlocked; agreement via Cohen’s kappa; Wilson intervals only after labels exist.
  • No accuracy, precision, recall, confidence interval or improvement claim is made anywhere in this report.
