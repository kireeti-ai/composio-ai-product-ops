03 · RESEARCH ENGINE

A repeatable path from product to evidence

The agent reduces manual searching and organizing. It does not replace a person’s judgement about identity, product access, or whether a quotation proves a claim.

What Composio contributed

Composio Connect MCP supplied search and page-fetch tools for official developer sources. The pipeline saved source URLs, retrieval times, and content hashes, then checked that calls were zero-charge. The installed Composio Python SDK (0.27.0) was exercised separately, see the demonstration below.

Run the research agent

Stages, each writing to a new run folder. Credentials come from a local .env.

  1. Retrieve official sources through Composio MCP (free, no model): python3 src/retrieve_wave.py runs/<new_dir> <id,id,...>
  2. Extract with the frozen prompt and schema: python3 src/run_p1.py --run <run_id>. It refuses to run without an APPROVED.json in the run folder and stops at the first quota error. Provider quota is currently exhausted, so no new extraction was run for this page.
  3. Verify with an independent model: python3 src/verify_v2.py --out runs/<run>/verify --records "<glob>"
  4. Assemble and build: python3 src/assemble_dataset.py <out_dir> label=<run_dir> ... then python3 -I src/build_report.py <DATASET.json> report/index.html

One-command check (offline): ./reproduce.sh. Live Composio trigger: .venv/bin/python src/composio_demo.py runs/composio-demo-<new-id>. Source: kireeti-ai/composio-ai-product-ops-research.

Technical implementation

The client connects to Composio Connect MCP and invokes its search/fetch tool schemas. Retrieval records and extraction records are stored separately. The report does not infer a toolkit exists from its name appearing in search results.

src/mcp.py, retrieval run ledgers, and per-page hashes are listed under Proof and Reproducibility.

What the evidence checks mean

  • A supported quotation is contiguous text from a retrieved source and maps to the cited URL.
  • An unsupported quotation means the submitted evidence does not support the claim as written; the claim itself may still be true.
  • Unknown, not found, inferred, and unsupported remain separate states.
  • Public API documentation does not by itself prove that access is self-serve.
  • Model agreement and JSON validity are not accuracy measures.
