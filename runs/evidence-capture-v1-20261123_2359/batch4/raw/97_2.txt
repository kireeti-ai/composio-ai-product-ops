How do I access Higgsfield via CLI?
Higgsfield
3 min
Copy page
CLI and Skills is how Higgsfield integrates with coding agents. The difference from MCP: MCP is a full connection for chat agents that exposes all tools with free parameter selection, while CLI and Skills is optimized for coding agents, where each skill has a defined structure that reduces token overhead and produces consistent output. Accessing Higgsfield through the CLI falls under the Developer Terms in the Terms of Use : keep your session secure, and you're responsible for what a coding agent generates through your account. Both use the same Higgsfield account and plan credits with no API key (API keys belong to the Higgsfield API, a separate developer product), and Unlimited models and free generations don't apply to either. See the setup guide and full skill list on the Skills landing page .

How do I set up CLI + Skills?
Install skills: run npx skills add higgsfield-ai/skills . This pulls three skills: generate, soul, and product-photoshoot.
Sign in: run higgsfield auth login . No API key needed.
Generate: in your coding agent, call /higgsfield:generate or say "Generate an image with Higgsfield." The agent picks the skill and runs it.
Compatible with Claude Code, Cursor, Codex, and other agents that support Skills or MCP.
What are the three Skills?
generate , image and video generation from any Higgsfield model (Soul, Nano Banana Pro for images; Seedance, Kling, Veo for video), up to 4K. The agent selects a model automatically, or you can specify one.
soul , train a Soul character from photos. The skill handles upload, training, and naming. See How do I create and use a Soul ID character?
product-photoshoot , turn a product link or images into studio-quality product shots and video ads. Works for physical products and apps.

Got any questions left?
What is the difference between CLI Skills and the Skills inside Supercomputer?
Two separate systems with the same name. CLI Skills are installed via npx skills add higgsfield-ai/skills for coding agents. Supercomputer Skills are built-in functions called with "/" inside the Supercomputer chat. They are not interchangeable.
Do I need both CLI and MCP?
No. Use MCP for chat agents like Claude web, and CLI for coding agents like Claude Code or Cursor.
Which models are available through CLI?
All Higgsfield models. The agent selects automatically unless you specify one.
My reference images aren't being passed to the generation. What do I do?
Update to the latest CLI version by re-running npx skills add higgsfield-ai/skills . Earlier versions had an issue with passing references; current versions pass all references, including images, correctly.
Do I need to reinstall the skills after updates?
Run npx skills add higgsfield-ai/skills again to pull the latest version.
Where do CLI generations appear?
In your Assets on higgsfield.ai , the same as web and MCP generations.
