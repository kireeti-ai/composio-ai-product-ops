Understand the rate limits that apply to the ClickUp API.
Rate Limits
The ClickUp API applies rate limits per token. These limits apply to both personal and OAuth tokens and vary by 
Workspace
 Plan of the Workspace hosting the token.
Rate Limits by Workspace Plan
Plan
Limit/minute*
FreeForever
100
Unlimited
100
Business

Enterprise / Enterprise Plus
10,000
* requests per minute per token.
E
rror handling
If you exceed the rate limit, the API returns a 
HTTP 429
 status code.
The response header on error contains
X-RateLimit-Limit
 - Current rate limit for the token.
X-RateLimit-Remaining
 - Number of requests remaining in the current rate limit window.
X-RateLimit-Reset
 - Time when the rate limit will reset, in Unix timestamp format.
