# iPayX Protocol

> FINTRAC-registered (MSB C10001283) FX forensic audit layer. Real-time foreign-exchange auditing API and MCP server for AI agents, Canadian CFOs, and fintechs. iPayX Protocol detects hidden FX markup on bank statements, wires, and card transactions by comparing applied bank rates to the live mid-market rate at the timestamp of execution.

## Tools

- check_fx_mid_market_rate: Live mid-market rate for a currency pair.
- audit_fx_transaction: Score one FX transaction: FX Score, spread %, hidden fees in dollars.
- compare_fx_sources: Compare bank rates vs alternative providers.
- full_forensic_fx_report: Full forensic FX report (PDF). No API key required; shares the free allowance of 3 audits per IP per month.
