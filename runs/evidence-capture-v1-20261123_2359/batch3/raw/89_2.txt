Coding agents
# Claude Code
claude mcp add --transport http ramp https://mcp.ramp.com/mcp
# Codex
codex mcp add ramp --url https://mcp.ramp.com/mcp
Coding agents can also use the CLI.
What the connection can do
The connection acts as the Ramp user who authorized it and never exceeds that
user's permissions. On the consent screen, the user chooses Full access or
Read-only. Connections expire after 30 days; reconnect to renew. Admins
control who can connect with the Manage connections to Ramp via MCP, CLI and
other AI connectors role permission and can revoke connections; revoking one
cuts off every AI tool that shares it. See
Manage connected AI tools.
Developer API
Use the API when your product owns the interface and backend workflow. Your
team is responsible for OAuth, scopes, webhooks, retries, and the customer
experience.

Custom MCP clients
Point the client at https://mcp.ramp.com/mcp. For the Ramp sandbox
(demo.ramp.com, the same environment as the CLI's --env sandbox), use
https://demo-mcp.ramp.com/mcp. Clients that read MCP JSON usually expect:
{
 "mcpServers": {
 "ramp": {
 "url": "https://mcp.ramp.com/mcp"
 }
 }
}
Custom clients and gateways need their exact redirect URI allowlisted before
authorization can complete:
Use https://, or http:// only with localhost or 127.0.0.1. Ramp also
accepts the claude://, cursor://, grokbot://, and perplexity-app://
schemes; other custom schemes are not supported.
Submit the exact host. Wildcard subdomains are not supported.
Request redirect URI access
for the client or gateway.
Troubleshooting
Authentication stops working
Connections expire after 30 days. Disconnect and reconnect Ramp in the client to
renew. If a custom client keeps stale credentials, clear its cached MCP auth.
Write tools are missing
The connection may be read-only. Reconnect and choose Full access, and
check that the user's Ramp role allows the action.
The CLI keeps logging out
CLI sessions stay signed in while they are used and refresh on each use. After
a period of inactivity, run ramp auth login again. If it happens sooner,
confirm that the runtime preserves ~/.config/ramp/config.toml; ephemeral
coding environments may replace that file between sessions.
A query returns too much data
Reporting queries return up to 1,000 rows per page. Narrow the date range or
filters, or ask the agent to page through the results.
Unsupported redirect URI
See Custom MCP clients to submit the exact URI.
A receipt attachment does not reach MCP
Chat attachments are not forwarded to Ramp MCP. Ask the agent for a receipt
upload link, or use the Ramp CLI or Ramp app.← PreviousGetting StartedOverviewNext →IdentityGuides
