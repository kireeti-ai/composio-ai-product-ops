Set up Gemini Notebook for business

This page describes the start-up tasks that you must complete to set up
Gemini Notebook for business.
After you have performed the tasks on this page, your users can
start creating and using notebooks in Gemini Notebook for business.
About identity setup
To complete the setup, you must have your organization's identity provider (IdP)
configured in Google Cloud.
Correct setup for identity is important for two reasons:
It lets your users use their current corporate credentials to access the
Gemini Notebook for business user interface.
It ensures that users see only the notebooks which they own or which have
been shared with them.
Supported frameworks
The following authentication frameworks are supported:
Cloud Identity:
Case 1: If you use Cloud Identity or Google Workspace, then all
user identities and user groups are present and managed through
Google Cloud. For more information about Cloud Identity, see the
Cloud Identity documentation.
Case 2: You use a third-party IdP, and you have synced
identities with Cloud Identity. Your end users use
Cloud Identity to
authenticate before accessing Google resources or Google Workspace.
Case 3: You use a third-party IdP, and you have synced
identities with Cloud Identity. However, you are still using your
existing third-party IdP to perform the authentication. You
have configured SSO with Cloud Identity such that your users begin
their sign in using Cloud Identity and then get directed to your
third-party IdP. (You might have already done this sync when
setting up other Google Cloud resources or Google Workspace.)
Workforce Identity Federation: If you use an external identity
provider (Microsoft Entra ID, Okta, Ping, PingFederate, or
another OIDC or SAML 2.0 IdP), but don't want to sync your
identities into Cloud Identity, then you must set up
Workforce Identity Federation in Google Cloud
before you can turn on data source access control for Gemini Notebook for business.
The google.subject attribute must map to the email address field in the
external IdP. The following are example google.subject and
google.groups attribute mappings for commonly used IdPs:
Microsoft Entra ID
Microsoft Entra ID with OIDC protocol
google.subject=assertion.email.lowerAscii()
google.groups=assertion.groups
Microsoft Entra ID with SAML protocol
google.subject=assertion.attributes['http://schemas.xmlsoap.org/ws/2005/05/identity/claims/name'][0].lowerAscii()
google.groups=assertion.attributes['http://schemas.microsoft.com/ws/2008/06/identity/claims/groups']
Microsoft Entra ID with a large number of groups
If you use Microsoft Entra ID and have more than approximately 150
groups, then you should follow the setup procedures for a large number
of groups.
google.subject=user.emails[0].value.lowerAscii()
google.groups=group.externalId
Note: If you use System for Cross-domain Identity Management
(SCIM) (or extended
attributes), the google.groups attribute mapping is ignored.
Okta
Okta with OIDC protocol
google.subject=assertion.email.lowerAscii()
google.groups=assertion.groups
Okta with SAML protocol
google.subject=assertion.subject.lowerAscii()
google.groups=assertion.attributes['groups']
You can select only one IdP per Google Cloud project.
Before you begin
Before starting the procedures on this page, make sure that one of the following
is true:
You use Cloud Identity as your IdP, or
You use a third-party IdP and have configured SSO with
Cloud Identity, or
You use a third-party IdP that is not Okta and have:
Set up Workforce Identity Federation by following the instructions
in
Configure Workforce Identity Federation with Microsoft Entra ID and sign in users or, if you have
more than approximately 150 groups, in Configure Workforce Identity Federation
with Microsoft Entra ID with a large number of groups .
If you follow the
Configure Workforce Identity Federation with Microsoft Entra ID and sign in users instructions,
make sure to do the recommended
security best practice steps to add a group
claim
and select All groups . This is a required step for
Gemini Notebook for business.
Set up SCIM. See Configure SCIM in Microsoft Entra
ID .
SCIM is necessary for autocomplete of user emails and group
names
and for Microsoft Entra ID with
a large number of groups .
You use Okta as your third-party IdP and have:
Followed the instructions in
Configure Workforce Identity Federation with
Okta .
Set up SCIM. See Configure SCIM in Okta .
SCIM is necessary for
autocomplete of user emails and group
names .
Plan your Workforce Identity Federation configuration
If you use Workforce Identity Federation, do the following before your users start
creating notebooks:
Map google.subject by using .lowerAscii() in the attribute mapping of
your workforce identity pool provider, as shown in the examples in
Supported frameworks .
Gemini Notebook for business matches user identities exactly.
If your IdP asserts a user's email address with uppercase letters in one
sign-in and lowercase letters in another, the user is treated as two
different users. Sharing a notebook with a manually entered email address
also works only when the address matches the asserted identity exactly.
Don't change the google.subject mapping after your users have started
creating notebooks. The mapping is part of each user's identity. If you
change it, existing notebooks, licenses, and shares no longer match the
users who own them.
Set the session duration of the workforce identity pool to cover your
users' workday. You can set a duration of up to 12 hours by using the
--session-duration flag of the gcloud iam workforce-pools update
command. The default session duration is one hour.
Federated sign-in sessions can't be refreshed silently. When the pool
session expires, users are redirected to the sign-in page and lose unsaved
chat conversations. For more information, see
Update a pool .
Create a project and enable the API
If you already have a Google Cloud project that you want to use, start at step
2.
Sign in to your Google Cloud account. If you're new to
Google Cloud,
create an account to evaluate how our products perform in
real-world scenarios. New customers also get $300 in free credits to
run, test, and deploy workloads.
In the Google Cloud console, on the project selector page,
select or create a Google Cloud project.
Roles required to select or create a project
Select a project : Selecting a project doesn't require a specific
IAM role—you can select any project that you've been
granted a role on.
Create a project : To create a project, you need the Project Creator role
( roles/resourcemanager.projectCreator ), which contains the
resourcemanager.projects.create permission. Learn how to grant
roles .
Note : If you don't plan to keep the
resources that you create in this procedure, create a project instead of
selecting an existing project. After you finish these steps, you can
delete the project, removing all resources associated with the project.
Go to project selector
Verify that billing is enabled for your Google Cloud project .
Enable the Discovery Engine API, if it is not already enabled.
Roles required to enable APIs
To enable APIs, you need the serviceusage.services.enable permission. If you
created the project, then you likely already have this permission through the
Owner role ( roles/owner ). Otherwise, you can get this permission through the
Service Usage Admin role ( roles/serviceusage.serviceUsageAdmin ).
Learn how to grant roles .

Grant the Cloud NotebookLM Admin role
As the project owner, you need to assign the Cloud NotebookLM Admin role to any
users who you want to be able to administer Gemini Notebook for business in this project:
In the Google Cloud console, go to the IAM page.
Go to IAM
Select the project.
Click person_add Grant access .
In the New principals field, enter the user identifier.
This is typically the email address for a Google Account or a user
group.
In the Select a role list, select Cloud NotebookLM Admin .
For more information, see
User
roles .
Click Save .
Set the IdP for Gemini Notebook for business
The project owner or a user who has the Cloud NotebookLM Admin role can set up
the IdP.
In the Google Cloud console, go to the Gemini Notebook for business
page.
Gemini Enterprise
Set Identity settings to Google identity provider or
Third-party identity provider .
For more information, see About identity setup above.
If you are using a third-party IdP and
Workforce Identity Federation, then specify the name of your
workforce pool and your Workforce pool provider .
Copy the Link .
You will send out this link to all the end-users of
Gemini Notebook for business. This
is the link to the user interface that they'll use to create, edit, and share
notebooks.
Optional: Register customer-managed encryption keys
If you want to use customer-managed encryption keys (CMEK) instead of Google
default encryption, then follow the instructions to register a key for
Gemini Notebook for business in Customer-managed encryption keys .
Typically, you only need to use CMEK if your organization has strict regulatory
requirements or internal policies that stipulate control over encryption keys.
In most situations, Google default encryption is sufficient. For general
information about CMEK, see the Cloud Key Management Service documentation .
Important: Register your key before your users start creating notebooks.
Any notebooks created before the CMEK encryption is set up, won't be protected.
Grant Gemini Notebook for business roles to users
This section describes how to give your users the IAM roles that
they need to access, manage, and share notebooks.
In the Google Cloud console, go to the IAM page.
Go to IAM
Select the project.
Click person_add Grant access .
In the New principals field, enter the user identifier. This is
typically the email address for a Google Account, a user group or the
identifier for a user in a workforce identity pool. For details, see
Represent workforce pool users in IAM policies , or
contact your administrator.
In the Select a role list, select Cloud NotebookLM User
role.
Click Save .
In addition to the Cloud NotebookLM User role, users need a license for
Gemini Notebook for business. See Get licenses for
Gemini Notebook for business .
Note: The subscription page displays the previous name NotebookLM Enterprise.
